Diese Seite ist eine SEPARATE technische Neufassung der Kaffee-Tafel.

Cappuccino und Café Crema als freigestellte neue Glas-Motive.

Optische Feinabstimmung gegenüber der freigegebenen Originalgrafik ist noch nötig;
insbesondere der ursprüngliche Hintergrund wurde hier in CSS nachgebaut.
